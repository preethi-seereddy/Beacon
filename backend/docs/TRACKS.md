# Track fit — honest read

## Strong

**NVIDIA / Nemotron — the biggest prize, and you were about to miss it.**
Your original write-up never mentions Nemotron. It says "an AI model will
interpret natural-language requests" — make that model Nemotron and you're in.
Their bar is "beyond a chatbot: multi-step workflows, tool integration,
real-world applicability", and Beau already matches it: *"the ramp by the
library is blocked"* → resolve the location → ask which ramp → file the report →
re-route affected users. That's a plan, not a reply. Prize is 2x RTX 5080.

**Photon 2.0.** The iMessage companion is exactly the intended use. Note the
separate **Voice Call** prize ($300) — a phone call is arguably a *better* fit
for accessibility than text, and far fewer teams will attempt it.

**Design.** Cyberpunk neon plus Clarity Mode is a genuinely interesting tension
— most "accessible" hackathon projects are beige. Make Clarity Mode a real
toggle on stage, not a slide.

**Overall.** Automatic.

## Weak — be honest with yourselves

**Virality.** This is the shakiest claim. "Can't wait to share" does not
describe a broken-elevator report. Leaderboards and points are bolted on, and
judges have seen a hundred of them. A real hook would be something like a
shareable *"this route is 4 minutes longer if you use a wheelchair"* card for a
specific building — an indictment, not a gamification badge. Either find that
hook or drop the track and spend the time on Nemotron.

**Beginner.** Only if the majority of your team are first-timers. Free prize if
so — check and claim it.

**Hardware.** No fit without adding a sensor. Don't force it.

## Scope warning

Four tracks, an A* router, community verification, a Supabase backend, an
iMessage agent, and a Leaflet map is more than a weekend. Suggested cut:

1. Router + route comparison UI **(done — this is your differentiator)**
2. Beau on Nemotron with 3 tools, text only
3. Reports writing to Supabase and changing routes live
4. Map, if time
5. Leaderboard — only if everything else ships

A demo where someone texts "elevator in the library is broken" and the website's
route visibly changes 5 seconds later wins more than five half-features.
